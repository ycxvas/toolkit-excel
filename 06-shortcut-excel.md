# Shortcut Excel

Daftar untuk Windows. Di Mac, umumnya `Ctrl` diganti `Cmd`, tetapi ada pengecualian (misalnya `F4` jadi `Cmd+T`). Kalau ada yang tidak jalan, cek di menu terkait.

## Navigasi dan seleksi

| Shortcut | Fungsi |
|---|---|
| `Ctrl+Panah` | Lompat ke tepi data |
| `Ctrl+Shift+Panah` | Pilih sampai tepi data |
| `Ctrl+Home` / `Ctrl+End` | Ke A1 / ke sel terakhir yang berisi |
| `Ctrl+A` | Pilih semua |
| `Ctrl+Spasi` | Pilih seluruh kolom |
| `Shift+Spasi` | Pilih seluruh baris |
| `Ctrl+Page Up` / `Ctrl+Page Down` | Pindah sheet |
| `F5` atau `Ctrl+G` | Go To (lompat ke sel tertentu) |
| `Ctrl+F` | Cari |
| `Ctrl+H` | Cari dan ganti |

## Mengedit

| Shortcut | Fungsi |
|---|---|
| `F2` | Edit isi sel |
| `F4` | Ganti jenis referensi ($) saat mengedit rumus; ulangi tindakan terakhir di luar mode edit |
| `Ctrl+Z` / `Ctrl+Y` | Batalkan / ulangi |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Salin / potong / tempel |
| `Ctrl+Alt+V` | Paste Special |
| `Ctrl+D` | Isi ke bawah dari sel di atas |
| `Ctrl+R` | Isi ke kanan dari sel di kiri |
| `Ctrl+Enter` | Isi seluruh sel terpilih dengan isi yang sama |
| `Alt+Enter` | Baris baru di dalam satu sel |
| `Ctrl+E` | Flash Fill |
| `Ctrl+Shift++` | Sisipkan sel, baris, atau kolom |
| `Ctrl+-` | Hapus sel, baris, atau kolom |
| `Ctrl+9` / `Ctrl+0` | Sembunyikan baris / kolom |
| `Delete` | Hapus isi sel |

## Rumus

| Shortcut | Fungsi |
|---|---|
| `Alt+=` | AutoSum |
| `Ctrl+\`` | Tampilkan semua rumus (tekan lagi untuk kembali) |
| `F9` | Hitung ulang |
| `Shift+F3` | Insert Function |
| `Ctrl+Shift+Enter` | Rumus array pada Excel versi lama |
| `Ctrl+;` | Tanggal hari ini (nilai tetap) |
| `Ctrl+Shift+;` | Jam sekarang (nilai tetap) |

## Format

| Shortcut | Fungsi |
|---|---|
| `Ctrl+1` | Format Cells |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | Tebal / miring / garis bawah |
| `Ctrl+Shift+1` | Format angka dengan pemisah ribuan |
| `Ctrl+Shift+3` | Format tanggal |
| `Ctrl+Shift+4` | Format mata uang |
| `Ctrl+Shift+5` | Format persen |
| `Ctrl+Shift+&` | Beri garis tepi |
| `Ctrl+T` | Ubah data menjadi tabel |
| `Ctrl+Shift+L` | Aktifkan atau matikan filter |

## File dan sheet

| Shortcut | Fungsi |
|---|---|
| `Ctrl+S` | Simpan |
| `F12` | Simpan sebagai |
| `Ctrl+N` | Buku kerja baru |
| `Shift+F11` | Sheet baru |
| `Ctrl+P` | Cetak |
| `Ctrl+W` | Tutup buku kerja |

## Menu lewat keyboard (Alt)

Tekan `Alt` untuk memunculkan huruf petunjuk di ribbon, lalu tekan hurufnya. Contoh: `Alt` lalu `H` membuka tab Home. Tidak perlu dihafal, cukup ingat bahwa semua menu bisa dijangkau tanpa mouse.
